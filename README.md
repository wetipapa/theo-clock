# 웨티의 시간 대작전 🕐

6~8세 어린이를 위한 시계 읽기 · 시간 감각 교육 웹게임입니다. 주인공 **웨티**가 하루 동안 유치원 버스를 타고, 밥을 먹고, 놀고, 목욕하고, 잠자리에 드는 이야기를 따라가며 아이가 직접 시곗바늘을 돌려 시간을 맞춥니다.

모바일(세로 화면)을 우선으로 디자인했고, 태블릿·PC에서도 자연스럽게 보입니다. 백엔드·회원가입·유료 API가 전혀 없으며 모든 진행 상황은 브라우저 로컬 저장소에만 저장됩니다.

## 실행 방법

```bash
npm install
npm run dev       # http://localhost:5173
```

환경변수가 필요 없어 클론 후 바로 실행됩니다.

### 그 외 스크립트

```bash
npm run build      # 프로덕션 빌드 (tsc + vite build)
npm run preview    # 빌드 결과 로컬 미리보기
npm run test       # vitest 단위 테스트 실행
npm run lint       # oxlint 정적 분석
```

## 주요 기능

- **6단계 학습 스테이지**: 정각 → 30분 → 10분 → 5분 → 시간의 흐름(몇 분 후/전) → 웨티의 하루 완성. 스테이지를 깨야 다음 단계가 열립니다(부모 설정에서 미리 열어둘 수도 있음).
- **4가지 게임 방식**을 스테이지 성격에 맞게 섞어서 출제합니다.
  1. 시곗바늘 맞추기 — 직접 드래그로 시침·분침 조작
  2. 알맞은 시계 고르기 — 4개의 아날로그시계 중 정답 고르기
  3. 시간의 흐름 — "지금 3시, 30분 후는?" 같은 경과 시간 문제
  4. 하루 일정 완성하기 — 카드를 시간표의 올바른 시간에 배치
- **문제는 매번 새로 생성**됩니다(고정 문제 세트 아님). 시드 가능한 PRNG로 생성 로직 자체는 단위 테스트로 검증했습니다.
- **아날로그 시계 엔진**: 포인터(터치/마우스) 각도를 누적 계산해 12시 경계를 넘나들어도 점프 없이 자연스럽게 회전합니다. 분침을 돌리면 시침도 실제 시계처럼 비례해서 따라 움직입니다. 스테이지 난이도에 맞춰 정각/30분/10분/5분 단위로 스냅됩니다.
- **좌절 없는 피드백**: 오답이어도 "틀렸어" 대신 "긴 바늘을 조금 더 돌려볼까?" 같은 구체적 힌트를 주고, 반복해서 틀리면 힌트가 점점 더 구체적으로 강화됩니다. 정답을 대신 입력해주지 않고 아이가 마지막 조작을 하게 합니다.
- **보상/진행도**: 문제를 풀면 별을 얻고, 별로 웨티의 방을 꾸밀 아이템(러그, 곰인형, 스탠드 등 8종)을 해금합니다. 목숨/게임오버 없음.
- **개인화**: 첫 실행 시 아이 이름을 입력하면 이후 모든 문구에 자연스럽게 반영됩니다.
- **부모 설정 화면**: 간단한 계산 문제로 보호되는 별도 화면에서 이름 변경, 효과음 on/off, 움직임 줄이기, 학습 진행도 확인, 스테이지 직접 열기, 우리 아이 일정 몇 가지 기록, 데이터 초기화(확인 절차 포함)를 할 수 있습니다.
- **효과음**: 외부 음원 없이 Web Audio API로 직접 합성한 짧은 사운드(버튼, 스냅, 정답, 보상)만 사용합니다. 사운드를 꺼도 플레이에는 지장이 없습니다.
- **PWA 지원**: 홈 화면에 설치해 오프라인에서도 기본 화면을 열 수 있습니다.
- **접근성**: 버튼에 aria-label 부여, 정답/오답을 색상 외에 아이콘·모양·문구로도 구분, 큰 터치 영역, `prefers-reduced-motion` 및 설정 내 "움직임 줄이기" 지원.

## 기술 스택 & 구조

- Vite + React 19 + TypeScript, Tailwind CSS v4
- 상태 관리: React Context + `useReducer` (`src/state`), 진행 상황은 `localStorage`에 자동 저장
- 시간 계산/문제 생성 로직은 UI와 분리되어 있습니다 (`src/lib`)
  - `time.ts` — 12시간제 시간 변환, 덧셈, 스냅, 12시 경계 처리
  - `clockGeometry.ts` — 포인터 각도 계산(순수 함수)
  - `problemGenerator.ts` — 스테이지별 문제 생성
  - `hints.ts` — 오답 힌트 로직
  - `korean.ts` — 을/를, 으로/로, 이에요/예요 등 받침 유무에 맞는 조사 처리
  - `audio.ts` — Web Audio 효과음
  - `storage.ts` — localStorage 안전 래퍼
- 화면(`src/screens`), 게임 모드 컴포넌트(`src/components/game`), 시계 엔진(`src/components/clock`)로 관심사를 분리했습니다.

### 테스트

`npm run test`로 58개의 단위 테스트를 실행합니다. 시간 변환·정답 판정·문제 생성·12시 경계 처리·조사 선택·리듀서 로직을 다룹니다. 시계 드래그 조작(포인터 각도 누적, 12시 경계 통과, 시침 단독 조작 시 분 유지 등)은 개발 중 Playwright로 실제 브라우저에서 검증했습니다.

## 배포 (Vercel)

이 프로젝트는 정적 빌드 결과물만 생성하는 순수 프론트엔드 앱이라 환경변수 설정 없이 바로 배포할 수 있습니다.

**방법 1 — Vercel CLI로 바로 배포**

```bash
npm install -g vercel
vercel
```

**방법 2 — GitHub 연동**

1. 이 폴더에서 `git init && git add -A && git commit -m "init"` 후 GitHub 저장소에 푸시
2. [vercel.com](https://vercel.com)에서 New Project → 저장소 선택
3. Framework Preset: Vite (자동 인식), Build Command: `npm run build`, Output Directory: `dist`

## 남아 있는 제한사항

- "우리 아이 일정" 커스텀 기능은 부모 설정에 기록·저장되지만, 아직 실제 문제 생성 로직에는 연결되어 있지 않습니다(추후 확장 지점으로 `src/state/gameState.ts`의 `customSchedule`을 활용할 수 있습니다).
- 아이콘·캐릭터·배경은 모두 직접 그린 SVG/이모지 대체 없는 자체 그래픽이며, 상세 일러스트보다는 단순하고 또렷한 플랫 스타일을 택했습니다.
- 오디오는 짧은 합성음 위주라 실제 악기/보이스 사운드는 없습니다.
